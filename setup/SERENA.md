# Serena: navegación semántica

Usar cuando ya exista código y ayude a localizar símbolos, referencias o impacto entre archivos. Activar proyecto actual al comenzar implementación si está disponible, conforme a AGENTS.

En fase 0 solo hay documentos y un script auxiliar; buscar y leer archivos es suficiente. No activar ni crear memorias para inventar arquitectura.

## Fuente de verdad

Serena ayuda a comprender implementación. Sus memorias no sustituyen decisiones aceptadas de `docs/13`, alcance de `docs/01`, requisitos ni reglas de AGENTS. No interpretar decisiones propuestas como aceptadas.

## Configuración y comprobación

Consultar [CODEX_TOOLS](CODEX_TOOLS.md) para fuente oficial y política de instalación. Mantener instrucciones de instalación en un solo lugar, verificándolas cuando se necesiten. Consultar [VERIFY_TOOLS](VERIFY_TOOLS.md) para prueba no destructiva de capacidad. El ejemplo `.codex/config.toml.example` es heredado y requiere validación antes de uso.
