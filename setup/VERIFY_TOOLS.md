# Comprobación de herramientas cuando corresponda

No realizada durante fase 0; no confundir herramientas enumeradas con herramientas conectadas. Verificar solo las necesarias y usar documentación actual para comandos del cliente instalado.

| Herramienta | Comprobación no destructiva | Evidencia esperada |
|---|---|---|
| Context7 | Resolver biblioteca concreta y consultar un concepto actual | ID elegido, documento pertinente y fuente |
| Playwright | Abrir frontend existente, inspeccionar roles y completar flujo autorizado | Pasos observados y resultado; dos contextos para dos jugadores |
| Superpowers | Solicitar análisis antes de implementación | Diseño proporcional y respeto a puerta de aprobación |
| Serena | Activar directorio actual e inspeccionar símbolo existente y referencias | Rutas y relaciones semánticas reales, sin modificar código |
| Chrome DevTools | Inspeccionar red/consola de frontend existente | Errores o mediciones observados, sin atribuir resultados hipotéticos |
| Ponytail | Revisar solución existente contra requisito | Simplificación que conserve comportamiento, errores y accesibilidad |
| Caveman | Revisar respuesta compacta | Conserva rutas, negaciones y hechos; documentación no pierde contexto |

Registrar herramienta, fecha, tarea, resultado y límites en progreso de la fase si la capacidad afecta su aceptación. Si falta un MCP, reportarlo y usar alternativa proporcionada; no instalar automáticamente para una tarea que no lo necesita.
